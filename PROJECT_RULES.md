# Project guidance index

This file is retained as a compatibility entry point for existing tools. Follow
the current, maintained guidance instead of duplicating project rules here:

- [`AGENTS.md`](AGENTS.md) — repository-wide AI coding instructions.
- [`.ai/rules/index.md`](.ai/rules/index.md) — path-specific rules and matching
  rule files.
- [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) — branches, commits and pull
  requests.
- [`docs/CODING_STANDARDS.md`](docs/CODING_STANDARDS.md) — Laravel and domain
  implementation conventions.
- [`docs/TESTING.md`](docs/TESTING.md) — test strategy, test data and commands.

The API is Laravel 13 and requires PHP 8.4.1 or newer. Its web and mobile
consumers live in separate repositories; keep public response contracts
coordinated and documented.
