# Security policy

## Reporting a vulnerability

Do not report vulnerabilities in a public issue, pull request, screenshot, or
discussion. Use GitHub's **Report a vulnerability** flow in the repository's
Security tab when private vulnerability reporting is enabled. If it is not
available, contact a repository maintainer privately and include only the
minimum information needed to reproduce the issue.

Do not include production credentials, access tokens, real invoices, tax or
vehicle identifiers, personal information, or customer data in a report. The
maintainers will acknowledge the report, investigate it privately, and
coordinate a fix and disclosure with the reporter.

## Supported releases

Security fixes are made against the default branch. Users should update to the
latest supported release or deployment from that branch.
